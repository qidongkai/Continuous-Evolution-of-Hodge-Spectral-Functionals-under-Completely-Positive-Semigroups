# Continuous-Evolution-of-Hodge-Spectral-Functionals-under-Completely-Positive-Semigroups
This repository provides the official codebase for the paper "Continuous Evolution of Hodge Spectral Functionals under Completely Positive Semigroups." It contains the numerical implementations and data pipelines necessary to reproduce the theoretical and empirical results presented in the manuscript. The core mathematical framework is implemented in Python, utilizing gudhi for simplicial complex construction and scipy for matrix exponential evolution, ensuring that all numerical operations rigorously align with the definitions and theorems established in the paper.

The project is organized into modular directories. The src/ directory houses the fundamental algorithms, including the construction of the Hodge Laplacian, the generation of three distinct CPTP quantum channel families, and the computation of the regularized cohomological dimension. The experiments/ directory contains executable scripts that directly reproduce the numerical verifications. Notably, the script verifying Theorem 3.9 demonstrates the exactness of the evolution equation at finite cutoff by comparing the numerical derivative of the spectral functional with the theoretical right-hand side.

To ensure immediate usability and reproducibility, the repository includes synthetic data generators and unit tests. Running the Bitcoin order-flow consistency check (Section 5) is facilitated by an included proxy dataset, allowing users to verify the numerical operability of the framework without requiring external data downloads. Full instructions for installing dependencies, executing the experiments, and accessing the pre-processed empirical data are provided in the accompanying documentation. This codebase is intended to serve as a transparent and reproducible foundation for future research at the intersection of topological data analysis, quantum channel semigroups, and spectral geometry.
